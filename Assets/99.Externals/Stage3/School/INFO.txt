The Pachage contains a collection of 72 modular assets to create a school scene.

--INFO--
Textures: 4K (Msx Resolution) 
Vertices: 4K on Average per Object (7.5K Max Vertices)
Materials: All materials uses Unity's build-in Shaders
Coliders: All prefabs have Mesh Coliders

Note: Demo scene baked with "Bakery" lighting system.
